Opening paragraph. Say what the page answers, in the words the reader would use.

## First thing

Prose, a table, a list, or a fenced example. Anything that is not a `##` heading and not
a `yaml step` block is prose.

## Second thing

Command examples belong in fenced blocks:

```bash
sop validate
```

## Where this page lives

A help page is plain Markdown in `help/`, so it can be edited in any text editor and it
reviews like any other change. The filename and `help_id` must match.
