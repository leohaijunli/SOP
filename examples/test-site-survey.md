A minimal test checklist to exercise the Open file flow. It uses only sections,
subsections, and checklist items.

## Preparation

- [ ] Confirm the site is accessible
- [ ] Notify the landowner

### Tools

- [ ] Tape measure packed
- [ ] Field laptop charged
- [ ] Spare batteries ready

## Field measurements

- [ ] Mark the start point
- [ ] Record the baseline bearing

### Grid layout

- [ ] Lay out the first line
- [ ] Place a marker at each end

### Reference readings

- [ ] Take a background reading away from the site
- [ ] Note the instrument height

## Wrap up

- [ ] Copy logs to the laptop
- [ ] Check the battery before packing

### Data handover

- [ ] Back up the raw file
- [ ] Confirm the checksum
