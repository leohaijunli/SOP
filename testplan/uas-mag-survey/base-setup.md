Set up the base so every rover fix traces back to a reference.

## Base location

- [ ] Base on a known or logged point with clear sky
- [ ] No reflective surfaces nearby
- [ ] Antenna height measured and recorded
- [ ] Base latitude and longitude logged

## Logging

- [ ] Base logging at 1 Hz or better
- [ ] Fix type fixed before starting
- [ ] Fix type recorded (fixed / float / single)
